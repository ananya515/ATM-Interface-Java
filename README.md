# 🏧 ATM Interface - Java Project

## 📌 Project Overview
The ATM Interface is a simple console-based Java application that simulates basic ATM operations.  
This project demonstrates core Object-Oriented Programming (OOP) concepts in Java such as classes, methods, encapsulation, and user interaction.

---

## 🚀 Features
- 🔹 Check Account Balance
- 🔹 Deposit Money
- 🔹 Withdraw Money
- 🔹 Input Validation
- 🔹 User-Friendly Console Menu
- 🔹 Proper Success & Error Messages

---

## 🛠️ Technologies Used
- Java
- OOP (Object-Oriented Programming)
- Scanner Class for user input
- 
## 📂 Project Structure

ATMInterface.java

### Classes Used:
- **BankAccount Class**
  - Stores account balance
  - Handles deposit and withdrawal operations
  - Returns current balance

- **ATMInterface Class**
  - Contains the main method
  - Displays ATM menu
  - Connects user input with BankAccount methods
